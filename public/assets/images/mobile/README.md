# FMB Mobile Visual Assets

This folder is reserved for the approved mobile FMB News experience.

Required production assets:

- `fmb-mobile-home-hero.webp` — exact user-supplied cinematic global-newsroom hero image with the gold FMB shell emblem centered.
- `fmb-daily-brief-coffee.webp` — approved dark-plum coffee mug with gold FMB shell emblem, visible coffee, warm bokeh and steam.

Do not silently omit either visual from the mobile home.

If either binary is missing during implementation, recover the exact approved asset from the current design handoff/user-supplied files or prepare a faithful optimized production version before final QA. Do not replace the hero with a generic stock newsroom image and do not replace the coffee visual with an envelope-only graphic.

See `docs/fmb-mobile-home-design-handoff.md` for layout, palette and acceptance rules.
